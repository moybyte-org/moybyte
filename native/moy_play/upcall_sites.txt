# (docs/kernel_cartpath_2026-10.md §4). tests/test_upcall_sites.py holds the
# tree to this list: a site added, moved or removed fails it until its row is
# written here, with the class it is counted under or why it is no crossing of
# its own.

# A row: file, enclosing function, sites in it, then what it is.
#   counted CLASS   a crossing moy_loop counts (CONSOLE APP DRIVER SERVICE ROLE)
#   inside FN       part of the crossing FN counts
#   binding         Python called this C; it calls back within that call
#   vm              the VM's own start, on the VM's task with no loop running
